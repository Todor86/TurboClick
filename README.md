# 📱 TurboClick (Clicker-Speedometer)

**TurboClick** is an interactive mobile clicker application that blends traditional clicker mechanics with an automotive aesthetic. The main user interface is styled after a car speedometer, where your click-per-second (CPS) speed directly translates into virtual km/h performance!

---

## 🎨 Design & UI/UX Features
This project was developed with a strong focus on visual storytelling, branding, and user experience:
- **Custom Branding:** Created a unique app logo and visual style inspired by classic racing game aesthetics.
- **User Interface:** Carefully structured UI layouts and intuitive user flows designed from scratch in **Figma**.
- **Ergonomics:** The interface elements are fully optimized for seamless, comfortable one-handed mobile gameplay.

---

## ⚡ Functionality & Mechanics
- **Speedometer Mechanics:** Dynamic real-time calculation tracking click frequency and updating the visual gauge indicator.
- **Smooth Animations:** Interactive UI feedback and realistic speedometer needle movement powered by CSS Transitions and Animations.
- **DOM Manipulation:** All core gameplay logic, score tracking, and state updates are handled using pure, vanilla JavaScript.
